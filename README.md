# Sahl Home (سهل هوم)

An AI-powered mobile real estate application built for the Saudi market to help users search, explore, and discover residential properties efficiently.

## Features
- **Property Discovery:** Mobile-first browsing interface focused on usability and accessibility.
- **Smart Recommendations:** Rule-based personalization engine that suggests properties based on user preferences and browsing behavior.
- **Neighborhood Insights:** Local area context to help users evaluate residential locations.

## Tech Stack
- **Frontend:** Flutter, Dart
- **Backend & Database:** Supabase
- **AI & Personalization:** Custom rule-based recommendation logic
